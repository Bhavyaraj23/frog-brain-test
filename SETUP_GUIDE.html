1 What are all these files?

You received 4 files. Here is what each one does:

📁 frog-brain-test/ ← your project folder (create this)
  ├── package.json    ← tells Node what packages to download
  ├── server.js      ← the backend server (handles data)
  ├── database.js    ← sets up the SQLite database
  └── 📁 public/
       └── index.html  ← the game itself (frontend)
💡
Simple explanation Think of it like a restaurant: index.html is the menu (what users see), server.js is the kitchen (processes orders), and database.js sets up the record book where all results are stored.
2 Install Node.js
ℹ️
What is Node.js? Node.js lets your computer run JavaScript outside a browser — it's the engine that powers our server.
Step 2.1

Go to the Node.js website

Open your browser and go to: https://nodejs.org

Click the big green button that says "LTS" (Long Term Support). This is the stable version.

Step 2.2

Install it

Run the downloaded file. Click Next → Next → Install. Leave all settings as default.

Step 2.3

Verify installation

Open a Terminal (Mac: press Cmd+Space, type "Terminal") or Command Prompt (Windows: press Win key, type "cmd"). Then type:

node --version

You should see something like v20.11.0. If you do — Node.js is installed! ✅

3 Create your project folder
Step 3.1

Create a folder on your Desktop

Create a new folder called frog-brain-test on your Desktop (or anywhere you like).

Step 3.2

Create a subfolder called "public"

Inside frog-brain-test, create another folder called public.

Step 3.3

Place the files correctly

Copy the files you received into this structure:

📁 frog-brain-test/
  ├── package.json
  ├── server.js
  ├── database.js
  └── 📁 public/
       └── index.html
4 Install the packages
📦
What are packages? Packages are pre-written tools we use. Like buying ingredients instead of growing them yourself. We need: Express (web server), SQLite (database), XLSX (Excel file creator), CORS (security).
Step 4.1

Open Terminal / Command Prompt IN your project folder

Mac: Right-click the frog-brain-test folder → "New Terminal at Folder"

Windows: Open the folder → click the address bar → type cmd → press Enter

Step 4.2

Run this one command

npm install

You will see lots of text scrolling. Wait until it finishes (1–2 minutes). A new folder called node_modules will appear — that's normal.

✅
Success looks like: added 87 packages (number may vary)
❌
If you see "npm not found": Node.js did not install correctly. Go back to Step 2 and try again. Restart your computer first.
5 Run the game on your computer
Step 5.1

Start the server

In the same Terminal / Command Prompt, type:

node server.js

You should see:

🐸 ══════════════════════════════════════════
   Frog Brain Test Server running!
   🎮 Game:    http://localhost:3000
   📊 Admin:   http://localhost:3000/admin
   📥 Excel:   http://localhost:3000/api/download
🐸 ══════════════════════════════════════════
✅ Database ready at: /path/to/frog_results.db
Step 5.2

Open the game in your browser

Open Chrome, Firefox, or Safari and go to:

🎮 http://localhost:3000

The game will load! 🎉

⚠️
Keep the Terminal open — if you close it, the server stops. The game needs the server running to save data.
Step 5.3

To stop the server

In the Terminal, press Ctrl + C (on Mac too). To start again, run node server.js.

6 Play the game & record data
Step 6.1

Enter the subject's name

On the Start screen, there is now a name input field at the top. Type the test subject's name (e.g. "Ramesh Kumar" or "Test Subject 1").

⚠️
The game will not start without a name. The name will be saved with the results.
Step 6.2

Play the game

Tap "गेम शुरू करें" to start. Play normally — tap frogs as they appear.

Step 6.3

View recorded data on Result screen

After the game ends, you will see a Hit Timing Data table showing:

ColumnMeaning
Hit #Which round (1 through 6)
Time (sec)How many seconds from game start when the tap happened
Result✅ Tapped / ❌ MISSED

You will also see a green "Data save ho gaya!" message confirming it was saved to the database.

7 View results in Admin Dashboard
Step 7.1

Open the Admin page

While the server is running, go to:

📊 http://localhost:3000/admin

You will see a dark dashboard with:

  • Total tests taken
  • Average score across all subjects
  • How many scored ≥5 (healthy) vs ≤2 (alert)
  • A full table of every test result with all hit timings

Step 8.1

In the Admin dashboard, click the green "📥 Download Excel (.xlsx)" button.

OR go directly to:

📥 http://localhost:3000/api/download

Double-click the downloaded file. It opens in Microsoft Excel, LibreOffice Calc, or you can upload it to Google Sheets (sheets.google.com → File → Import).

9 Host online FREE — Railway.app
🌐
Why host online? Right now the game only works on your computer. To share it with others — patients in a clinic, family members — you need to put it on the internet. Railway gives you a free URL.
Step 9.1

Create a free GitHub account

Go to github.com → Sign up (it's free). GitHub is where we store your code so Railway can find it.

Step 9.2

Create a new GitHub repository

After logging in to GitHub:

  1. Click the + button (top right) → "New repository"
  2. Name it frog-brain-test
  3. Make it Public
  4. Click "Create repository"
Step 9.3

Upload your files to GitHub

On the GitHub repository page:

  1. Click "uploading an existing file"
  2. Drag and drop: package.json, server.js, database.js
  3. Create the public folder: click "Create new file" → type public/index.html → paste the contents
  4. Click "Commit changes"
Step 9.4

Add a Procfile (tells Railway how to start your app)

Create a new file in your GitHub repo called Procfile (no extension) with this content:

web: node server.js
Step 9.5

Deploy on Railway

  1. Go to railway.app → Sign up with your GitHub account
  2. Click "New Project" → "Deploy from GitHub repo"
  3. Select your frog-brain-test repo
  4. Railway will automatically detect it's a Node.js app and deploy it
  5. After 1–2 minutes, click "Generate Domain" in the Settings tab
  6. You get a URL like https://frog-brain-test-production.up.railway.app
🎉
Your game is now live! Share the URL with anyone. Results are saved to Railway's database automatically. To download Excel: go to your-url.railway.app/api/download
Step 9.6

Important: Add a persistent volume for the database

Railway's free plan resets files on redeploy. To keep your data permanently:

  1. In Railway, go to your project → Volumes → Add Volume
  2. Mount path: /app/data
  3. In database.js, change DB_PATH to use /app/data/frog_results.db
⚠️
Without this step, data is deleted every time Railway restarts your app. Download Excel regularly as a backup.
11 Common problems & fixes
Problem Fix
npm not found Reinstall Node.js from nodejs.org. Restart computer.
EADDRINUSE port 3000 Another app is using port 3000. Change 3000 to 3001 in server.js line: const PORT = 3001
Game loads but data doesn't save Make sure the server is running (node server.js). The game needs the server to save data.
Can't open localhost:3000 Server not running. Open Terminal → navigate to project folder → run node server.js
Excel file is empty No games played yet. Play at least one game first, then download.
Cannot find module 'better-sqlite3' Run npm install again in the project folder.
Railway deployment fails Make sure package.json has "start": "node server.js" in scripts.
Font looks different / broken You need internet for Google Fonts to load. No internet = system font (that's fine).
